# GitHub Actions 最小 CI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 BabyPluginFramework 添加 GitHub Actions CI：build / test / lint 三个 job 在 push 到 main 及 PR 时运行，并在双语 README 加 build 徽章。

**Architecture:** 一个 workflow 文件（`.github/workflows/build.yml`）含三个独立并行的 job，均为 ubuntu-latest + Temurin JDK 17 + Android SDK。lint job 要严格通过，需先在 `app/build.gradle.kts` 禁用 `MissingClass`（插件框架固有误报：宿主 manifest 声明的插件组件类不在宿主 classpath，运行时从插件 APK 加载）。

**Tech Stack:** GitHub Actions（actions/checkout@v4、actions/setup-java@v4、android-actions/setup-android@v3）、Gradle 8.11.1 wrapper、AGP 8.9.1。

**Spec:** `docs/superpowers/specs/2026-10-05-github-ci-design.md`

**本地环境（验证步骤用）：**
```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
```

### Task 2: 创建 CI workflow

**Files:**
- Create: `.github/workflows/build.yml`

- [ ] **Step 1: 创建 workflow 文件**

创建 `.github/workflows/build.yml`，内容如下（完整内容，逐字写入）：

```yaml
name: build

on:
  push:
    branches: [main]
  pull_request:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
          cache: gradle
      - name: Set up Android SDK
        uses: android-actions/setup-android@v3
      - name: Build
        run: ./gradlew assembleDebug

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
          cache: gradle
      - name: Set up Android SDK
        uses: android-actions/setup-android@v3
      - name: Run unit tests
        run: ./gradlew testDebugUnitTest

  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'
          cache: gradle
      - name: Set up Android SDK
        uses: actions/setup-android@v3
      - name: Run lint
        run: ./gradlew lintDebug
```

- [ ] **Step 2: YAML 语法校验**

```bash
python3 -c "import yaml,sys; d=yaml.safe_load(open('.github/workflows/build.yml')); assert set(d['jobs'])=={'build','test','lint'}; assert d[True]['push']['branches']==['main']; print('YAML OK, jobs:', list(d['jobs']))"
```

Expected: 输出 `YAML OK, jobs: ['build', 'test', 'lint']`。
（注意：YAML 1.1 中 `on` 会被解析为布尔键 `True`，所以断言用 `d[True]`，这是正常现象不是错误。）
若 python3 无 yaml 模块：`python3 -m pip install pyyaml --quiet` 后重试。

- [ ] **Step 3: 提交**

```bash
git add .github/workflows/build.yml
git commit -m "(ci) Add GitHub Actions workflow with build, test and lint jobs"
```

Expected: 提交成功，1 个新文件。
